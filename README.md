# Eextramile AI — 3D Continuous Scroll Landing Page

A minimal, high-fidelity 3D and scroll-driven landing page experience built for **Eextramile AI**.

The experience visualizes the end-to-end automated recruiter outreach pipeline: from candidate highlight extraction and 3D origami dispatch to verified recruiter discovery, adaptive AI email drafting, smart multi-day follow-ups, and instant bounce credit refunds.

---

## ✨ Features & Architecture

- **Physical Envelope & Stationery Metamorphosis**:
  - Precision 3-panel origami stationery letter nestled inside an opaque luxury pocket sleeve.
  - Seamless pocket emergence, 3D panel unfolding, pen-stroke milestone verification, refolding in thirds, and wax medallion sealing.
- **3D Origami Dispatch**:
  - Faceted 3D paper airplane geometry with dynamic light shading and banking flight physics.
- **Studio Display Workstations**:
  - Space-gray aluminum unibody enclosures with cantilever stands, cable pass-throughs, and dark glass anti-glare reflection.
  - High-confidence recruiter targeting with emerald laser scans and floating email address extraction.
- **Adaptive Composer & Dispatch**:
  - Chassis expands into a frosted Gmail-style composer with word-by-word highlight injection.
  - Multi-workstation delivery with live inbox notification badges.
- **Precision Mechanical Chronometer**:
  - Brushed titanium knurled bezel with luminous indices and skeleton watch hands spinning across a 4-day automated follow-up timeline.
- **Bounce Shield & Executive Vault**:
  - Delivery intercept alert compresses into a heavy minted 3D gold coin (`+1 CREDIT`) with 720° spin.
  - Parabolic coin refund into the Obsidian & Platinum Executive Credit Vault with dynamic counter increment (`50` → `51 Credits`).

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, TypeScript)
- **3D Graphics**: [Three.js](https://threejs.org/) & [React Three Fiber](https://r3f.docs.pmnd.rs/) (`@react-three/fiber`, `@react-three/drei`)
- **Animation & Scrubbing**: [GSAP](https://gsap.com/) & [GSAP ScrollTrigger](https://gsap.com/scrolltrigger/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```
